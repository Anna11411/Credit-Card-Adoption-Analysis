# Credit Card Adoption Analysis

An R and Quarto practice analysis by Anna Shaju using a **synthetic 240-row dataset**. It explores customer characteristics associated with accepting a credit card offer. The report includes charts, city summaries, and an exploratory logistic regression. It does not claim validated out-of-sample prediction performance.

## Run locally

1. Install R, RStudio, and Quarto.
2. In R, run `install.packages(c("readxl", "ggplot2"))` once.
3. Open `report.qmd` in RStudio and click **Render**. Keep the `data` folder alongside the report.

The data are dummy practice data. The previous analysis script was used as a reference; the report provides a shorter, cleaned version. Check and understand the analysis before presenting it as your own work.
